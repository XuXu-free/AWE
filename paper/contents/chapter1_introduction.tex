\chapter{绪论}

\section{研究背景与意义}

\subsection{电解水制氢与波动性电源适配}

在全球应对气候变化的大背景下，实现碳达峰、碳中和（``双碳''目标）已成为世界各国的共同使命。
氢能因其零碳排放特性，是工业、交通等领域深度脱碳的核心载体之一。
特别是利用可再生能源电解水制取的``绿氢''，其全生命周期碳排放接近于零，
是交通、化工等领域实现深度脱碳的重要选择。

目前，电解水制氢技术主要包括碱性电解水（Alkaline Water Electrolysis, AWE）、
质子交换膜电解水（PEM）和固体氧化物电解水（SOEC）三种主流技术路线。
其中，AWE技术已有数十年工业化应用历史，单体设备成本低、系统成熟度高，
是目前兆瓦级及以上制氢项目的主流选择。

\subsection{波动性电源适配挑战}

随着风电、光伏等可再生能源装机规模的快速增长，其间歇性和波动性特征对电网稳定运行构成了持续压力。
电解水制氢系统作为大规模可调节负荷，是消纳波动性可再生能源的重要途径。
但这也要求电解系统具备更强的宽功率运行能力：

\begin{itemize}
  \item \textbf{宽功率范围}：需要在20\%--150\%额定功率范围内稳定运行
  \item \textbf{快速响应}：需跟踪秒级至分钟级的功率波动
  \item \textbf{安全约束}：需确保温度、氢气纯度等关键参数始终处于安全范围
\end{itemize}

\subsection{多槽协调控制难点}

大型电解制氢项目通常采用多槽并联的模块化架构以提高系统灵活性和可靠性。
四槽并联系统是常见的工业配置，但多槽协调控制面临以下挑战：

\begin{enumerate}
  \item \textbf{热耦合}：多个电解槽共用换热器和分离器，形成复杂的热力学耦合
  \item \textbf{气相耦合}：分离器气相空间共享，氢气传输相互影响
  \item \textbf{功率分配}：总功率约束下各槽的最优负荷分配问题
  \item \textbf{安全约束}：氢气至氧侧传输量（HTO）等关键安全指标的严格约束
\end{enumerate}

\section{国内外研究现状}

\subsection{传统控制方法}

传统的电解系统控制主要采用PID控制和模型预测控制（MPC）。
PID控制结构简单、易于实现，但难以处理多变量耦合和约束条件。
随着可再生能源渗透率的提高，电解系统在动态工况下的热力学建模与控制优化受到广泛关注~\cite{Zhong2025AppliedEnergy}。

非线性模型预测控制（NMPC）能够显式处理系统非线性、多变量耦合和约束条件，
在电解系统控制中展现出良好性能~\cite{Qi2022AppliedEnergy,Survey2024Hydrogen}。
但NMPC需要在每个控制周期内在线求解非线性优化问题，单次求解耗时2--5秒，
在分钟级控制周期下仍难以满足实时性需求。
这促使研究者寻找计算效率更高的替代方案。

\subsection{AI驱动控制方法}

近年来，人工智能技术为工业控制提供了新的解决思路。
强化学习（RL）通过与环境交互学习最优策略，已在多个控制任务中取得成功~\cite{Mnih2015Nature}，
但RL需要大量探索性试验，对高安全要求的电解系统存在应用障碍。

模仿学习（Imitation Learning）通过模仿专家行为学习策略，避免了危险的探索过程~\cite{Ross2011AISTATS}。
行为克隆（Behavior Cloning）通过监督学习建立从状态到动作的确定性映射，
是最简单的模仿学习方法，但存在分布漂移（Distribution Shift）问题，
且高斯输出假设难以刻画控制动作的多模态特性。

\subsection{生成模型方法}

扩散模型（Diffusion Models）是近年来生成模型领域的重要进展，
在图像生成、语音合成等任务中表现突出。
在机器人控制领域，扩散策略（Diffusion Policy）已被证明可有效学习复杂操作技能~\cite{Chi2023DiffusionPolicy}，
并展现出多模态动作分布建模能力。
但现有研究主要集中于机器人操作等离散任务，
将其用于具有严格安全约束的连续工业过程控制，特别是电解水制氢这类高能耗化工系统，
相关研究仍较少见。

\section{研究内容与主要贡献}

\subsection{研究内容}

围绕四槽并联AWE系统的协调控制问题，开展以下研究：

\begin{enumerate}
  \item \textbf{高保真物理建模}：建立包含电化学、热力学和氢气传输的多槽系统仿真模型

  \item \textbf{专家数据生成}：设计NMPC控制器作为专家，生成高质量训练数据

  \item \textbf{生成式控制策略}：提出基于扩散模型的预测控制策略

  \item \textbf{安全约束保证}：引入投影算子安全约束保证机制，确保关键约束的严格满足

  \item \textbf{实验验证}：构建完整的仿真平台，验证所提方法的有效性
\end{enumerate}

综上，现有研究在AWE系统协调控制中存在两个突出问题：
一是NMPC计算开销大，难以满足实时控制需求；
二是数据驱动方法（包括生成模型）在学习过程中缺乏对温度、HTO等安全约束的严格保证。
本研究即围绕上述问题展开。

\subsection{主要贡献}

本研究主要贡献包括：

\begin{itemize}
  \item \textbf{将扩散模型引入AWE系统协调控制}：
  探索了扩散模型在电解系统控制中的应用，
  验证了生成模型在工业过程控制中的可行性。

  \item \textbf{设计了面向多槽系统的安全约束保证机制}：
  结合投影算子安全约束保证机制与控制障碍函数（CBF）安全滤波~\cite{Ames2019CBF}，
  构建了适用于多槽AWE系统的安全控制框架，解决了生成模型可能输出不安全动作的问题。

  \item \textbf{建立了完整的仿真-训练-验证平台}：
  开发了四槽AWE系统的高保真仿真器，
  建立了从NMPC专家数据生成到扩散模型策略学习的完整实验流程。
\end{itemize}

\section{论文组织结构}

全文共分为四章，各章之间的逻辑关系如下：

\textbf{第一章 绪论}阐述AWE系统协调控制的研究背景，梳理传统控制、AI驱动控制和生成模型方法的研究现状，并指出当前研究在实时性与安全性方面的不足，明确研究内容与贡献。

\textbf{第二章 研究概述与技术路线}介绍四槽并联AWE系统的结构与控制目标，对比NMPC与Diffusion Policy两种技术路线的优劣，阐述所采用的``专家数据生成--扩散模型训练--安全约束闭环''整体研究框架。

\textbf{第三章 问题建模、仿真与控制器设计}是核心章节。该章依次建立多槽AWE系统的电化学、热力学和氢气传输模型，设计NMPC基线控制器，提出基于Diffusion TCN的生成式控制策略，给出投影算子和控制障碍函数（CBF）的安全约束保证机制及完整数学推导，并通过闭环仿真验证所提方法的有效性。

\textbf{第四章 结论与展望}总结主要结论与创新点，分析研究的局限性，并展望未来可能的改进方向。

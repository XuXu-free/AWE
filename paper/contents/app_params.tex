\chapter{实验设置}
\label{app:experiment_settings}


\section{实验对象与平台}

为验证所提方法在实际系统规模下的适用性，实验以四槽并联AWE系统（$N=4$）为对象，系统参数如表~\ref{tab:system_params}所示。

\section{硬件与软件环境}

仿真实验在以下软硬件平台下开展：
\begin{itemize}
  \item CPU：Intel Core i9-12900K
  \item GPU：NVIDIA RTX 4090（训练阶段）
  \item 内存：64GB DDR5
  \item Python 3.10，PyTorch 2.0，CasADi 3.6
\end{itemize}

\section{评价指标}

为定量对比各控制方法的综合性能，定义以下评价指标：

\begin{itemize}
  \item \textbf{功率跟踪}：$\mathrm{RMSE} = \sqrt{\frac{1}{T}\sum_{t=1}^{T}(P_{actual,t} - P_{ref,t})^2}$
  \item \textbf{温度调节}：$\mathrm{MAE}_T = \frac{1}{T}\sum_{t=1}^{T}\sum_{i=1}^{4}|T_{s,i,t} - T_{ref}|$
  \item \textbf{约束满足}：越界次数、越界持续时间
  \item \textbf{计算效率}：单次推理时间
\end{itemize}
